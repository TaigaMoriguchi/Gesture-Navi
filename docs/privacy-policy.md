# Gesture Ops プライバシーポリシー

最終更新日: 2026-03-28

## 1. 取得する情報

Gesture Ops は、ユーザーの端末カメラ映像を利用して手のランドマーク推定を行います。  
本拡張機能は以下の方針で動作します。

- カメラ映像は端末内でのみ処理します
- カメラ映像・ランドマーク・推定結果を外部サーバーへ送信しません
- 個人を特定できる情報を収集しません

また、拡張機能の動作状態を保持するために Chrome の `storage` を使用します。保存内容は以下です。

- ON/OFF状態
- モード設定・感度設定
- タブごとの認識状態（カメラ状態、手の検出状態、最終ジェスチャー）

## 2. 利用目的

取得した情報は、次の目的にのみ利用します。

- ジェスチャー認識機能の実行
- popup上の状態表示
- ユーザーが設定した操作感の維持

## 3. 第三者提供

本拡張機能は、取得情報を第三者へ販売・共有・提供しません。

## 4. 保存期間

設定情報は、ユーザーが拡張機能を削除するか、Chrome の拡張データを削除するまで端末内に保持されます。

## 5. 権限について

本拡張機能は以下の権限を使用します。

- `storage`: ON/OFFや感度設定の保存
- `tabs`: 有効タブへの状態同期
- `http://*/*`, `https://*/*`: 対象ページ上でのジェスチャー処理実行
