# ストア掲載文テンプレート

## 短い説明（132文字以内）

Webカメラで手の動きを認識し、戻る/進む・スクロール・ピンチ操作をページ上で行えるChrome拡張です。

## 詳細説明（たたき台）

Gesture Ops は、Webカメラ映像から手の動きをローカル推論し、Chromeブラウジングを補助する拡張機能です。  
デフォルトは「仮想カーソル + ピンチ」モードで、ページ内クリックやスクロール操作ができます。  
オプションで「スワイプ」モードに切り替えると、左右スワイプによる戻る/進む操作も利用できます。

### 主な機能

- 仮想カーソル表示（ページ内）
- ピンチクリック（短いピンチ）
- ピンチドラッグによる縦横スクロール
- 横引っ張りホールドによる戻る/進む（円形ゲージ表示）
- スワイプモード（4方向ジェスチャー）
- popupからON/OFF・感度調整・モード切替

### プライバシー

- カメラ映像は端末内でのみ処理
- 映像・推定データの外部送信なし
- 設定情報はChromeのローカルストレージに保存
